# 🪖 Alfa Gear – Equipamentos Táticos

O **Alfa Gear** é um projeto de desenvolvimento web que apresenta uma vitrine virtual de equipamentos militares e acessórios táticos. O site foi desenvolvido com HTML5 e CSS3, com o objetivo de exibir produtos, suas características e seus respectivos preços em uma interface organizada e intuitiva.

## 📌 Sobre o projeto

O projeto simula uma página de uma loja especializada em equipamentos táticos, permitindo que os visitantes visualizem diferentes produtos por meio de cartões individuais.

A página conta com uma barra de navegação, campo de pesquisa e uma vitrine de produtos organizada em uma grade responsiva.

## ✨ Funcionalidades

- **Barra de navegação:** links para início, sobre e contato.
- **Campo de pesquisa:** espaço destinado à pesquisa de produtos.
- **Vitrine de produtos:** apresentação de cinco equipamentos táticos.
- **Cards individuais:** cada produto possui imagem, nome, descrição e preço.
- **Botões de compra:** links ilustrativos para compra dos produtos.
- **Efeitos visuais:** animação dos cartões ao passar o mouse.
- **Layout adaptável:** grade de produtos que se ajusta a diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização dos elementos da página.
- **CSS3:** estilização, cores, espaçamentos, efeitos e organização visual.

## 🎨 Identidade visual

O projeto utiliza uma identidade visual inspirada no segmento de equipamentos táticos, com destaque para:

- Tons de verde e oliva.
- Cartões com bordas arredondadas.
- Imagens dos produtos.
- Textos em branco para melhorar o contraste.
- Efeitos de sombra e movimento nos cartões.

## 🚀 Como executar o projeto

1. Faça o download ou clone o repositório:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

2. Abra a pasta do projeto.
3. Verifique se o arquivo HTML, o CSS e as imagens estão na mesma estrutura de diretórios indicada no código.
4. Abra o arquivo `alfagear.html` em um navegador de internet.

Não é necessário instalar dependências ou utilizar ferramentas adicionais para visualizar a página.

## 🎯 Objetivo educacional

O projeto tem como finalidade praticar conceitos fundamentais de desenvolvimento web, como:

- Estruturação de páginas com HTML.
- Aplicação de estilos utilizando CSS.
- Criação e utilização de classes.
- Organização de elementos com CSS Grid e Flexbox.
- Construção de cartões para apresentação de produtos.
- Utilização de efeitos de transição e hover.
- Aplicação de regras de responsividade com Media Queries.
